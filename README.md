# AidPage Atlas — 시군구 재난 프로파일

전국 256개 시군구(표시 단위)를 규칙으로, 서열 없이 보여 주는 재난 프로파일입니다.
자연·사회 위해, 국가 지원 문턱(재정력 구간), 기록된 결과(재해연보 2012~2024), 대피 접근을 한 장씩 넘겨 봅니다.

- 주소: https://5-jihwan.github.io/aidpage-atlas/
- 2026-10-20 AidPage(재난 지원 안내, https://5-jihwan.github.io/aidpage/)에서 떼어 낸 독립 사이트입니다. 행정경계 등은 AidPage가 모으는 공개 자료의 그 시점 사본입니다.
- 이 저장소에는 화면과 그 화면이 읽는 자료만 있습니다. 자료를 만드는 스크립트와 이전 판 이력(태그 dex-v1.4 ~ dex-v1.7)은 당분간 AidPage 저장소(github.com/5-Jihwan/aidpage)에 있습니다.
- 판: dex-v1.7(타입 v1.4.2) · 인용: `CITATION.cff`
- 순위·점수가 아닙니다. 같은 단위 전국 상위 25% 같은 규칙 판정이며, 기록이 없다는 것이 안전하다는 뜻은 아닙니다.
